# 4IT433-git-guild
Repo used for sharing methodology of work with Git during 4IT433 course

You are more than welcome to contribute to this repository.
* Create a new branch for your changes and merge the changes to dev first.
* Create a pull request to merge your changes to main branch. The pull request will be reviewed by other team members and merged if approved.

If you have any questions, please contact the Git Guild via the dedicated [Teams channel](https://teams.cloud.microsoft/l/channel/19%3Ab183a764649b45c7bd96fc0870ef1004%40thread.tacv2/Odpoledni_Git%2C%20CI%2CCD%20a%20governance?groupId=f42500c7-8406-4492-82b1-2528e81665cb&tenantId=2b51a4b3-443f-4406-8ca4-19056a79a444)
